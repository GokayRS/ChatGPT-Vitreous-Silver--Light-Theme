# Vitreous Silver Light - ChatGPT

[English](#english) | [Español](#español)

## English

Custom theme for the ChatGPT web interface via Stylus. Designed with a sophisticated liquid glass aesthetic, fluid silver gradients, crisp custom typography (*Plus Jakarta Sans*), and a polished minimal workspace.

### 🌟 Key Features

* **Fluid Glassmorphism:** Translucent blurred panels (`backdrop-filter: blur(16px)`) with subtle white borders and silver depth shadows.

* **Continuous Background:** Unified fixed radial and linear gradients (`#cbd5e1` to `#f8fafc`) across the sidebar, composer, and suggestion menus for a seamless visual flow.

* **Custom Typography:** Integrated *Plus Jakarta Sans* with explicit support for native ChatGPT formatting attributes (bold, italic, headers, and monospace code blocks).

* **Responsive & Clean UI:** Expanded chat container width (up to 70% for user bubbles), polished floating controls, and hidden sidebar resize lines.

### 🚀 Installation

1. Install the **Stylus** extension for your browser ([Chrome](https://chrome.google.com/webstore/detail/stylus/clbfbmidbdobicbbnoobnhmoaikkdbec) / [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/)).

2. Click the link below to install the style directly:

   👉 [**Install Vitreous Silver Light ChatGPT**](https://raw.githubusercontent.com/GokayRS/ChatGPT-Vitreous-Silver--Light-Theme//main/vitreous-silver-light-chatgpt.user.css) *(Raw File)*

3. Stylus will open. Click **"Install Style"**.

## Español

Tema personalizado para la interfaz web de ChatGPT a través de Stylus. Diseñado con una sofisticada estética de cristal líquido (*liquid glass*), degradados plateados continuos, tipografía pulida (*Plus Jakarta Sans*) y un espacio de trabajo limpio y moderno.

### 🌟 Características Principales

* **Efecto Cristal Líquido:** Paneles translúcidos con desenfoque (`backdrop-filter: blur(16px)`), bordes blancos sutiles y sombras de profundidad en tonos plata.

* **Fondo Continuo y Unificado:** Degradado radial y lineal fijo (`#cbd5e1` a `#f8fafc`) aplicado a la barra lateral, el cuadro de chat y los menús flotantes para una experiencia visual fluida.

* **Tipografía Personalizada:** Integración de *Plus Jakarta Sans* respetando los atributos nativos de ChatGPT para negritas, cursivas, títulos y bloques de código monoespaciados.

* **Interfaz Limpia y Adaptativa:** Mayor ancho para las burbujas de chat (70%), controles flotantes pulidos y eliminación del tirador vertical de redimensionamiento.

### 🚀 Instalación

1. Instala la extensión **Stylus** en tu navegador ([Chrome](https://chrome.google.com/webstore/detail/stylus/clbfbmidbdobicbbnoobnhmoaikkdbec) / [Firefox](https://addons.mozilla.org/es/firefox/addon/styl-us/)).

2. Haz clic en el siguiente enlace para instalar el tema directamente:

   👉 [**Instalar Vitreous Silver Light ChatGPT**](https://raw.githubusercontent.com/GokayRS/ChatGPT-Vitreous-Silver--Light-Theme//main/vitreous-silver-light-chatgpt.user.css) *(Archivo Raw)*

3. Se abrirá Stylus automáticamente. Pulsa en **"Instalar estilo"**.
